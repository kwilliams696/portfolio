•Automated Book Advertisement Posting

My task assigned by my boss was to automate the posting of advertisements for specific books.

Technology Stack:

• Python
• Selenium
• XML
• Requests
• WebDriver Manager for Chrome
• ChromeDriver

Description

This script automates the process of posting book advertisements on a website. It reads book details from an XML file and posts them as advertisements. Below are the main steps and code snippets illustrating the key functionalities of the script.

1. Import Libraries and Configure WebDriver

First, the required libraries are imported, and the Selenium WebDriver is configured to use Chrome with custom user data and user agent settings.


    import os
    import time
    from selenium import webdriver
    from selenium.webdriver import Keys
    from selenium.webdriver.common.by import By
    import xml.etree.ElementTree as ET
    from selenium.webdriver.support.ui import WebDriverWait
    import requests
    import datetime
    from selenium.webdriver.chrome.service import Service
    from webdriver_manager.chrome import ChromeDriverManager
    from selenium.webdriver.chrome.options import Options
                        
    xml_file_path = "/your/path.xml"

    login = 'your login'
    password1 = 'your 1 part of password'
    password2 = 'your 2 part of password'

    user_agent = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/116.0.0.0 Safari/537.36"
    chrome_options = Options()
    chrome_options.add_argument("--user-data-dir=/your/path/User Data/")
    chrome_options.add_argument(f"user-agent={user_agent}")

    driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()), options=chrome_options)

The XML file containing book details is parsed, and the script navigates to the base URL of the advertisement website.
